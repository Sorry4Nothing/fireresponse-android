# FireResponse Android

Native Android-App (Kotlin, Jetpack Compose) für FireResponse, die App für Jugend- und Kinderfeuerwehren im Kanton Zürich: Übungen aus Lodur, Ja/Nein-Anmeldung, Kontakt und Push.

Das Backend liegt in [Sorry4Nothing/fireresponse-api](https://github.com/Sorry4Nothing/fireresponse-api). Die API-Beschreibung steht dort unter `docs/api/`.

Der Code folgt in den nächsten Pull Requests.
